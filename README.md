# C# Programming I

A university-level course covering the fundamentals of **C# programming**, event-driven programming, Windows Forms, methods, arrays, lists, file handling, and database connectivity using **ADO.NET**.

## 🎯 Course Objectives

By the end of this course, students should be able to:

* Understand the fundamentals of C# programming.
* Apply programming logic and problem-solving techniques.
* Understand event-driven programming.
* Develop graphical user interface applications.
* Work with methods, arrays, lists, and files.
* Connect C# applications with databases.
* Develop desktop applications using Windows Forms.

## 🧠 Learning Outcomes

After completing this course, students should be able to:

1. Understand Windows and event-driven programming.
2. Develop graphical user interface applications.
3. Apply programming logic to solve problems.
4. Use C# programming structures correctly.
5. Use methods to organize and reuse code.
6. Work with arrays and lists.
7. Connect applications to databases using ADO.NET.
8. Develop small- to medium-sized Windows desktop applications.

## 💻 Course Project

At the end of the semester, students will develop a **desktop application** that demonstrates the concepts learned throughout the course.

The project should demonstrate:

* User Interface Design
* Variables and Data Types
* Decision Structures
* Loops
* Methods
* Arrays or Lists
* Database Connectivity
* ADO.NET
* Desktop Application Development
